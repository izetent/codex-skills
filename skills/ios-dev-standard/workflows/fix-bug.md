# Fix Bug Workflow

1. 复述问题：
   - 实际表现
   - 期望表现
   - 触发路径
   - 影响范围
2. 收集证据：
   - 相关文件
   - 状态流
   - 生命周期
   - 日志或可复现步骤
3. 判断责任层：
   - UI/布局
   - 状态归属
   - 一次性事件
   - 导航
   - 网络/缓存/存储
   - 并发/生命周期
   - 设计系统
4. 根因明确后做最小修改。
5. 如果根因不清楚，先加窄范围日志或写验证路径。
6. 验证原始路径。
7. 验证邻近回归路径。

检验：如果移除这次修改，bug 是否会稳定回来？如果不能说明，根因可能还不够清楚。
