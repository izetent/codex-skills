# 功能验证

实现后使用本文件。

## 验证

- 新需求的主路径可用。
- 原有相邻业务路径仍然可用。
- 复用或抽离后的旧入口行为不变。
- 受影响的空态、异常态、加载态、权限态、取消态和重复触发路径。
- 如果改了公共接口、共享状态、存储、协议或跨端契约，验证所有已知调用方。
- 如果改了界面，至少检查关键尺寸、文案溢出、可访问性和不同设备/窗口形态。
- 如果改了异步或生命周期逻辑，验证取消、重入、页面退出后回调和重复请求。

## 报告

- 实现了什么。
- 为什么修改边界是最小且合理的。
- 哪些文件和层被修改。
- 新路径如何验证。
- 哪些旧路径做了回归验证。
- 哪些内容没有验证，以及剩余风险。
