# 日志手册

现有证据不足时使用本文件。

## 只在能回答具体问题的位置加日志

示例：

- 回调 `X` 是否触发？
- 哪个分支写入了状态 `Y`？
- 当前绑定的是哪个条目编号、请求编号、会话编号或业务编号？
- 实际输入、缓存、配置或权限状态是什么？
- 事件 `A` 是否早于命令 `B` 到达？

## 合适的临时日志点

- 生命周期边界
- 状态源写入和状态映射
- 事件分发和回调入口
- 网络响应映射
- 缓存读写和存储迁移
- 权限、配置、实验或功能开关分支
- 列表绑定、资源创建和资源释放

## 避免

- 输出无关大对象
- 在全应用范围打噪音日志
- 记录密钥、令牌、隐私数据或敏感业务字段
- 缺陷验证后继续在热路径保留高频临时日志

## 临时观测规则

如果添加临时日志：

- 范围要窄
- 命名要清楚
- 只回答一个具体问题
- 验证后移除或降噪，除非它仍有明确诊断价值
